# Benchmark metadata

This directory holds metadata about benchmark datasets and splits:

- `splits/`  -  train/validation/test split assignments (repository-level where
  possible, to reduce cross-contamination). Generated lazily when a dataset has
  enough entries.
- `sources/`  -  provenance records: where each entry came from (e.g. SWE-bench
  instance ids), when it was fetched, and the importer version used.

Splitting strategy is documented in `docs/research.md`. Split files are
generated by scripts; never edit them by hand.
